Project: SchemeSetu

Goal: Help users ask questions about government schemes and uploaded documents.

Features:
    - Chat interface
    - Government scheme search
    - PDF upload
    - RAG answering
    - Chat history
    - Citations(reference to a source of information) 
    - Authentication

Users:
    - Student
    - Citizen
    - Administrator

Functional Requirements:
    - Upload PDF
    - Ask question
    - Return answer
    - Show source

Non Functional:
    - Fast (<3 sec)
    - Works on low hardware
    - Modular
    - Testable
    - Accuracy
